# 🧠 RAG AI Automation Lab

AI automation and RAG projects with LangChain, embeddings, semantic search and intelligent agents using Python.

Este repositório reúne projetos práticos desenvolvidos com foco em arquiteturas RAG (Retrieval-Augmented Generation), busca semântica, embeddings e agentes inteligentes utilizando Python, LangChain e modelos LLM.

Os projetos demonstram como integrar IA com documentos reais para criar assistentes inteligentes capazes de responder perguntas contextualizadas utilizando recuperação de informações semânticas.

---

# 📋 Estrutura dos Projetos

O repositório contém três projetos desenvolvidos de forma evolutiva:

## ⚽ Projeto 1 — Assistente IA para Regras de Futebol

Sistema de perguntas e respostas utilizando PDF com regras de futebol.

### Funcionalidades

- Processamento de documentos PDF
- Chunking de documentos
- Embeddings
- Busca semântica
- Pipeline RAG
- Respostas contextuais com IA

### Tecnologias utilizadas

- Python
- LangChain
- OpenAI
- FAISS/ChromaDB
- Embeddings
- RAG
